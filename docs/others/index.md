# Specialized & Other Schemas Documentation

This section covers niche Schema.org types that don't fit into the major categories.

## Detailed Guides

*   [Niche & Technical Schemas](niche.md) - Life sciences, data types, and more.
*   [Statistics & Data Science](statistics.md) - Populations, observations, and variables.

## Core Architecture Reminder:
1.  **Thing**: The root of everything.
2.  **Types**: Categories of things.
3.  **Properties**: Attributes of types.
4.  **DataTypes**: The type of value a property can have.

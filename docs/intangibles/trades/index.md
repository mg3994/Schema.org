Documentation for independent contractors and skilled tradespeople.

*   [Plumbing & Hydraulic](plumbing.md) - Plumbers and pipe-fitters.

## Core Implementation Pattern

For most trades, the best approach is to define a `LocalBusiness` or `Person` that offers a `Service` through an `OfferCatalog`.

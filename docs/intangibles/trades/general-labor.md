# General & Niche Labor Schema

Documentation for general laborers and highly specialized manual workers.

## Comprehensive Example: High-Altitude Specialist (JSON-LD)

```json
{
  "@context": "https://schema.org",
  "@type": "Person",
  "name": "Marcus Peak",
  "jobTitle": "High-Altitude Laborer",
  "offers": {
    "@type": "Offer",
    "itemOffered": { "@type": "Service", "name": "Tower Cleaning" },
    "priceSpecification": {
      "@type": "UnitPriceSpecification",
      "price": "300.00",
      "priceCurrency": "USD",
      "unitText": "hour"
    }
  }
}
```

# Places Schema Documentation

A `Place` represents entities that have a physical extension.

## Detailed Guides

*   [Accommodations](accommodations.md) - Hotels, Rentals, Apartments.
*   [Real Estate](real-estate.md) - Listings, Floor Plans, Complexes.

## Other Categories
*   **Civic Structure**: Airports, Museums, Parks.
*   **Landform**: Mountains, Rivers.
*   **Tourist Attraction**: Places that attract tourists.
